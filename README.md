# TiruVeedu — Tiruvannamalai Travel & City Guide

TiruVeedu is a travel and city guide landing page for Tiruvannamalai, Tamil Nadu.

## Features

- **Hero Section:** City search bar, category quick links grid, and 75% left-to-right faded hero visual.
- **Explore Map Section:** Interactive 3D map of Tiruvannamalai with category filters and zoom controls.
- **Featured Listings:** Highlights for temples, EV bike rentals, auto rickshaw, and outstation taxi services.
- **Reviews & Quick Info:** Google rating score (5.0 stars), tourist testimonials, and 6 quick info cards (Girivalam full moon dates, temple timings, weather).
- **Plan Your Visit CTA Banner:** Travel guide CTA banner featuring the Arunachala mountain landscape.
- **Multi-column Footer:** Social links, quick links, legal info, and mountain backdrop artwork.

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm

### Development Server (Next.js)

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

### Build Production Application

```bash
npm run build
```

### Standalone HTML / CSS

You can also open `index.html` directly in any web browser without any build step.
